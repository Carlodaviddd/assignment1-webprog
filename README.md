# Assignment 1: Introduction to Web Programming

A vanilla web assignment with a **profile page**, **mark to grade converter**, **staff page**, and **temperature converter**.

## Features
- Profile page demonstrating basic web structure and styling
- Mark to grade converter using JavaScript logic
- Staff page with basic layout and styling
- Temperature Converter for **Celcius**, **Fahrenheit**, and **Kelvin**

## Technologies
- HTML
- CSS
- JavaScript

## How to See It
1. Clone this repository
2. Open the `index.html` file in your browser.
